# Java HTTP Web Sunucusu Ödevi

Bu proje, 3. parti herhangi bir harici kütüphane veya framework (`Spring Boot` vb.) kullanılmaksızın, yalnızca saf Java standart kütüphanesi (`com.sun.net.httpserver`) kullanılarak geliştirilmiş bir HTTP web sunucusudur.

## 🚀 Projenin Çalışma Prensibi ve Özellikleri
* Sunucu **1989** portu üzerinden gelen TCP bağlantılarını dinler.
* Tarayıcıdan `http://localhost:1989` adresine bağlandığında dinamik olarak şu HTML çıktısını üretir:
  * **`<h1>`** boyutunda Ad Soyad
  * **`<h2>`** boyutunda Öğrenci Numarası
  * Renkli, stillendirilmiş ve HTML bileşenleriyle biçimlendirilmiş kişisel biyografi kutusu.
